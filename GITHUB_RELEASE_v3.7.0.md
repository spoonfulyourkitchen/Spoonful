## Spoonful 3.7.0

Personalisation update.

- Existing users get a short profile refresh (allergies, diet, experience, household, cooking time, cuisines) with an explanation of why it helps.
- Meal logging: pick a recipe from your library with portions, or switch to manual entry.
- Barcode scanner: type the product code directly, photo capture only as fallback.
- Library filters and cuisine picker are dialogs again, with the library visible behind.
- Skill level rises over time, showing more and harder recipes; the AI Chef adapts.
- AI Chef now considers your target weight.
- New recipe form: photo, title, ingredients, steps, everything else in "Details".

No database changes needed.
