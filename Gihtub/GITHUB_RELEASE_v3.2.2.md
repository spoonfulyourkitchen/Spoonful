# Spoonful 3.2.2

**Focus:** stability. Nothing new to learn — the app now holds up better in daily use, uses less memory and battery, and tells you what went wrong if something does.

## Finds more deals, with the exact timeframe
* Energy drink deals are now searched through the **official offer search first**, then cross-checked against two further price sources running in parallel. If one source is unavailable, the others still deliver.
* Every offer shows the **store** and, when the source provides it, **how long the offer is valid** — so you know whether it is still worth a trip.
* Results stay sorted by **price per litre**, with the best deal and the cheapest can called out separately.
* Prices are cached, so the page opens with the last known offers immediately and only refreshes when you ask.

## Sharper pictures, smaller memory footprint
* Photos in all lists (Discover, My Recipes, Community) are now requested in the size they are actually displayed in, instead of loading full-resolution originals.
* If the small version cannot be loaded, the original is fetched automatically — nothing ever disappears.
* Result: noticeably smoother scrolling, less data usage and far fewer out-of-memory crashes on phones with limited RAM.

## If something goes wrong, you can see it
* A new **Recent errors** section in Settings lists what failed, when, and where it happened.
* The error screen now tells you that the problem was recorded and offers a **restart** instead of a dead end.
* Long-running requests are cut off automatically, so the app can no longer appear frozen while waiting for a reply.

## Daily handling
* The offline indicator now shows **how many changes are still waiting** to be synced.
* Adding ingredients no longer creates duplicates in your shopping list.
* Sharing a list with your household is protected against double taps.
* The cooking mode tells you when it resumes your last session, so you know why you are not on step 1.
* The live barcode scanner closes itself when left unattended.
* Age, height and weight accept both comma and dot as decimal separator.
* The camera crop tool shows the whole photo, lets you move the frame anywhere and supports two-finger zoom.

## Every text is translated
* Remaining English-only labels, dialogs and placeholders are now available in all ten supported languages: sign-in and password recovery, email confirmation, photo reporting, feedback, theme selection, cooking completion and the offline screen.
